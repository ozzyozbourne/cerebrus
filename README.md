# cerebrus

Material for learning and running the Cerebras SDK.

- **`course/`** is an 18-chapter visual course with five appendices on the Cerebras Wafer-Scale Engine, CSL programming, and a comparison with Tenstorrent and NVIDIA GPUs. It includes seven CSL programs validated on the SDK simulator (five written for the course, two adapted from SDK benchmarks). Start at `course/index.html`; `course/README.md` covers how to run and edit it.
- **`reports/`** and **`research_notes/`** hold the research report and per-topic notes the course is based on.
- **`.claude/skills/cerebras-sdk/`** is a skill and setup script that installs Cerebras SDK 2.10.1 in a cloud container and runs a smoke test.
