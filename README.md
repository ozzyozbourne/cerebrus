# cerebrus

Material for learning and running the Cerebras SDK.

- **`course/`** is a 15-chapter visual course on the Cerebras Wafer-Scale Engine, CSL programming, and a comparison with Tenstorrent and NVIDIA GPUs. It includes five CSL programs validated on the SDK simulator. Start at `course/index.html`; `course/README.md` covers how to run and edit it.
- **`reports/`** and **`research_notes/`** hold the research report and per-topic notes the course is based on.
- **`.claude/skills/cerebras-sdk/`** is a skill and setup script that installs Cerebras SDK 2.10.1 in a cloud container and runs a smoke test.
