How to use this course

  • Read in order the first time: each chapter builds on the previous one. Every chapter ends with "Check yourself" questions, and the lab chapters have exercises with expected answers.
  • Every number carries a provenance tag: Vendor Indep Analyst SDK 2.10.1 Measured Derived Unverified. Web figures were gathered largely from search extracts of primary sources; check them against the primary document before relying on them.
  • To run the programs: set up the SDK with .claude/skills/cerebras-sdk/scripts/setup.sh, then source /home/user/cerebras-sdk/env.sh and bash course/programs/run_all.sh.
  • The research behind the course is in reports/ and research_notes/ in this repository.
