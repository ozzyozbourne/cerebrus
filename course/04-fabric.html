The fabric: wavelets and colors

900,000 PEs share no memory. The only way data moves between them is the fabric: a 2-D mesh of routers passing 32-bit messages called wavelets, one hop per cycle, along routes fixed at compile time. Programming the WSE is largely the art of choosing those routes.

After this chapter you can

  • Describe a wavelet, a color, and a route (rx → tx) on one router.
  • Read and write @set_color_config for point-to-point, pass-through and multicast routes.
  • Explain why programs alternate colors in a checkerboard, and why colors are the scarcest resource.

A mesh of five-port routers

Every PE has a router with five bidirectional ports: NORTH, SOUTH, EAST, WEST to its neighbours, and RAMP down to its own compute engine. A link carries one 32-bit word per cycle and a hop takes about one cycle; the ramp takes about two Indep (arXiv papers). There are no long wires and no global bus: a message from one corner of the wafer to the other takes over a thousand hops.

Routes are static

For each PE and each color, the layout file declares a route: the set of ports a wavelet of that color is accepted from (rx) and the set it is sent to (tx). This is configured once, at load time; the router does no address lookup at run time. Here is the route pair from Lab 2's row reduction, sending from PE (0,0) to PE (1,0):

layout.csl
const c0: color = @get_color(0);
// PE (0,0): accept from my own CE, send EAST
@set_color_config(0, 0, c0, .{ .routes = .{ .rx = .{RAMP}, .tx = .{EAST} } });
// PE (1,0): accept from WEST, deliver down the RAMP to my CE
@set_color_config(1, 0, c0, .{ .routes = .{ .rx = .{WEST}, .tx = .{RAMP} } });

Three shapes cover most programs:

  • Point to point: rx RAMP → tx EAST at the sender, rx WEST → tx RAMP at the receiver.
  • Pass-through: rx WEST → tx EAST. The wavelet crosses the PE without touching its CE.
  • Multicast: rx NORTH → tx {RAMP, SOUTH}. One wavelet is copied to the local CE and forwarded, so one send reaches a whole column (Lab 2's broadcast).

Why programs alternate colors

A router's configuration for one color is a single rule. Consider a middle PE in a chain that must receive a partial result from the west and send its own result east. With one color, the router would need both rx WEST → tx RAMP and rx RAMP → tx EAST on the same color — and an incoming wavelet from the west could not be told apart from an outgoing one. Two same-colored wavelets meeting at a router in the same cycle is undefined behaviour Indep. The fix is to alternate colors by column parity: even columns send on c0 and receive on c1, odd columns the reverse.

Runtime flexibility: switches and filters

Switches

A color can hold up to four route positions (WSE-3 has 4 switch registers per color; WSE-2 has 1) SDK 2.10.1. A special control wavelet advances the position — e.g. send east, then west, then south — saving colors. Subtlety: the router switches only after the control wavelet passes, so its own payload follows the old route.

Filters

A range filter lets a PE accept only wavelets whose upper 16 bits fall in [min_idx, max_idx]. A whole row can share one broadcast stream while each PE keeps only its slice. WSE-2 has two filter banks, WSE-3 one. Color swap (flipping a color bit on each hop) exists only on WSE-2: "CSL currently does not support color swap on WSE-3" SDK 2.10.1.

Colors are the scarcest resource

The aggregate fabric numbers follow from this design: 32 bits × 4 directions × 2 × ~850k PEs × ~1 GHz ≈ 2 × 1017 bit/s, matching the vendor's 220 Pb/s for WSE-2 Derived. Each individual link, though, is only ~4 GB/s — the fabric is fast in aggregate, not between any two distant PEs.

Write the route for a PE that should forward color 5 from the north to the south without its CE seeing it.

@set_color_config(x, y, c5, .{ .routes = .{ .rx = .{NORTH}, .tx = .{SOUTH} } });

How many cycles does it take a wavelet to cross 100 PEs?

About 100 cycles of hops, plus ~2 cycles on each ramp. Latency grows linearly with distance, so algorithms favour nearest-neighbour communication.

Why can't a middle PE in a reduction chain send and receive on the same color?

One color has one routing rule per router. It cannot both deliver westward-arriving wavelets to RAMP and forward RAMP wavelets east without ambiguity, and collisions are undefined.
